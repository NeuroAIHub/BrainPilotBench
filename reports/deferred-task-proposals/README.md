The user requested this narrower scope on 2026-11-02. The original protocols and source audits remain available for reference.
No source data, prepared data, published HF files or validation results were removed.

| Proposal | Reason for deferral |
|---|---|
| [Airscope social competition](airscope-social-competition/README.md) | Only a 17-example processed subset was obtained. A separately defined small-sample task requires its own protocol and acceptance. |

The five accepted additions are three CalMS21 tasks and two MABe22 tasks. Their data and evaluation interfaces remain unchanged.

The 17-example subset is not silently promoted to a full task or substituted for the planned original-signal benchmark.
