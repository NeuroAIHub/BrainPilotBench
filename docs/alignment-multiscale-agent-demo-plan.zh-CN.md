## 一、已有任务落在综述的哪一层

Xu 等的综述 *Beyond Representational Alignment: Comparing Functional Organization in the Brain and Artificial Networks with a Multiscale Framework* 用表 1 定义**比较对象**，用表 2 区分**证据阶段**：识别、验证、因果检验、泛化。行为给五层提供共同参照。归类时要看人脑侧和模型侧各测到了什么。

| 层级 | 现有任务与证据边界 | 可做的拓展 |
|---|---|---|
| 1 · 单元 | Brain-Score 视觉协议包含用整层表示预测单个猕猴神经元的设计。现有语言任务多以体素或脑区均值为终点，尚缺模型单元的自主定位与选择性验证。 | 先在独立句子上验证模型单元的响应偏好。若要直接比较两侧单元，可用 Jamali 等的语言单细胞数据，按词和前文对齐，检验留出句子的调谐曲线。听语音与读转录的比较应限定在双方共有的词义信息。[论文](https://www.nature.com/articles/s41586-024-07643-2) · [数据](https://figshare.com/articles/dataset/Semantic_encoding_during_language_comprehension_at_single_cell_resolution/26046127) |
| 2 · 群体表征 | **主要覆盖层。** 旧 Task1 复现固定层脑预测，旧 Task2 选层后在同一批被试的新材料上确认。A 测简单变量之外的预测增量，B 改变模型前文，C 比较脑表征几何和人类判断，D 将静态模型表征与各时点 EEG 比较，F 用表示选出预期脑响应强弱不同的句子。 | 让 Agent 在固定预算内选择组件，在隐藏材料上与固定层、同规模随机组比较。C/D 可进一步让视觉模型接收人看到的同一张图片，解决目前以概念名代理图像的问题。 |
| 3 · 神经回路 | B 改输入、F 选刺激，都没有测两个内部组件之间传递了什么。找到一组有共同偏好的单元，只定位到候选功能组。 | 让 Agent 提出一条具体路径，例如某注意力头向一组 MLP 单元传递信息。替换该路径的激活，与替换其他路径比较，检验事前预测的输出变化。该干预支持模型侧判断，脑侧的路径对应还需独立测量。 |
| 4 · 网络组织 | F 将左半球语言网络汇总成一个响应值；D 测 EEG 的时间变化。两者均缺模块间的交互测量。 | 在两个任务条件下保留多脑区时间序列，为模型定义可区分的模块。用留出被试检验 Agent 对连接变化的预测，并比较只用各区平均活动的基线。可从 HCP 的 0-back／2-back 协议评估数据和刺激可比性。[HCP 协议](https://www.humanconnectome.org/hcp-protocols-ya-task-fmri) |
| 5 · 全系统组织 | E 测规则切换时人和模型的学习、迁移与干扰，提供行为参照。它缺少同期人脑全局组织变化的记录。 | 沿用 E 的规则切换问题，另选有多阶段脑记录的数据。在两侧预先定义全局重组指标，检验它能否预测留出规则下的错误和恢复。 |

A–F 已完成真实输入准备和维护者参考运行。A–E 主要评规定分析的正确性，F 已按冻结选择在隐藏人类数据上的实际效果评分。Brain-Score 扩展的 18 个复现和 6 个比较是协议实例，已记录真实端到端验证的是 Pereira384 × distilgpt2。独立 Agent 的新成绩应单独报告。[A–F 任务与验收](../tasks/alignment/TASKS_A_F_GUIDE.zh-CN.md) · [旧 Task2 契约](../tasks/alignment/REAL_PROFILE_CONTRACT.md) · [Brain-Score 验证记录](../tasks/alignment/brainscore/VALIDATION.md)

## 二、Agent 自动探索可解释性，哪些方法能迁移

被研究的 LLM 提供激活和可干预的组件；研究 Agent 决定看哪些例子、相信哪个解释、下一步做什么实验。最适合迁移的是让 Agent **在观察结果前写下两个解释各自预测什么**，随后用独立材料验证。要把这套方法用于脑–模型对齐，还需增加真实的人类测量终点。

| 方法来源 | 原工作怎么做 | 可迁移到本项目的做法 |
|---|---|---|
| InterpAgent，2026 预印本 | 根据功能问题生成探测文本，在激活空间检索候选特征，随后用正例、负例和竞争假设反复验证。 | 给功能目标，让 Agent 自选单元，并用同预算的固定 top-k 搜索衡量自主选择的价值。[论文](https://arxiv.org/abs/2605.01555) |
| Goodfire Neuron Scientist，2026 技术报告 | 查询不同激活强度的样例及上下游组件，依据开发集反馈修正描述，再用独立文本测试描述能否预测激活。 | 保存每轮的假设、反例、预测和修正；把未见样例上的预测表现作为解释质量的依据。[作者报告](https://www.goodfire.com/research/neurons-as-an-interpretable-basis) |
| HyVE / AgenticInterpBench，2026 | 给定已经定位的电路，让 Agent 提出解释，并用消融、激活替换等实验验证。其分析发现，不少失败发生在验证方案和执行环节。 | 单独评「能否检验解释」，给不同 Agent 同一候选组，比较其选择的对照和事前预测。[论文](https://arxiv.org/html/2606.24026v2) |
| AlKhamissi 等，NAACL 2025；Lepori 等，2026 预印本 | 前者将语言功能定位、模型单元消融、人脑预测连接起来；后者用稀疏特征预测语言脑区响应，并显式控制词的意外程度（surprisal）。 | 首版直接读取 MLP 单元，分别测模型行为和隐藏脑响应。用「简单变量」与「简单变量加候选单元」的留出预测差衡量增益。[功能定位](https://aclanthology.org/2025.naacl-long.544/) · [稀疏特征脑编码](https://arxiv.org/html/2606.06857v3) |

## 三、服务器上要做的三项任务

| 拟议任务 | Agent 拿到什么、决定什么 | 提交与独立评分 |
|---|---|---|
| G · 输入可比性审计 | 给实验协议、人类刺激与呈现记录、模型实际输入。检查可见前文、刺激、token 位置和反馈；案例同时包含合格协议与已知偏差。 | 提交逐项判断、证据和必要修正。评分看问题定位、误报和修正后的信息边界。 |
| H · 功能单元搜索 | 给已审计的刺激、模型激活查询接口和训练脑响应。Agent 在同一预算下选择层、单元组和读取位置。 | 提交冻结的单元列表、映射和逐句预测。评分看留出脑预测，以及相对简单控制和匹配随机组的增益。 |
| I · 解释检验 | 给候选单元和独立探测材料。Agent 提出至少两个能作出不同预测的解释，再选对照或干预。可直接使用预先提供的候选组，独立于 H 运行。 | 提交实验选择、事前预测和可重放记录。分别评分未见激活的预测、干预效应方向，以及结论是否符合观测。 |

| 可直接复用 | 首版需要新增 |
|---|---|
| 训练部分为 988 句、5 名参与者；候选部分为另外 500 句、3 名参与者。两组的句子和参与者均不重叠。人类终点是左半球语言网络的 fMRI 平均响应。 | 在 988 句内划分搜索与开发材料。同一原句及其所有改写留在同一分区；另留未用于搜索的模型探测句对。500 句的脑响应只由评分端读取。 |

### 实验顺序与主指标

1. **先定协议。** 核对模型和数据版本、分区、查询预算、候选组大小与随机种子。训练内完成单元选择、标准化和脑预测映射拟合。500 个候选句均为 6–8 词，落在 F 的同一个粗长度箱里；长度控制需核对实际词数、token 数、末词位置和标点。
2. **让两个解释作出不同预测。** 例如，Agent 观察到某组单元在完整句子中激活较高。一个解释是它们对词序敏感，另一个解释是它们主要响应末词位置。只改变中间词序、保持词集合与末词后，先记录预期方向，再查询激活。用独立句对复查。词序扰动也会影响流畅度和可预测性，因此结论保留在实际检验的扰动范围。
3. **检验模型侧作用。** 在新材料上对候选单元组和同层、同规模、激活强度相近的随机组做相同消融。两种条件都在模型读到目标词**之前**做干预，测同一目标词的对数概率变化。比较候选组与随机组的变化差，并保留方向。
4. **冻结后揭晓人类结果。** 用训练参与者的平均响应拟合逐句预测。基线使用词数、token 数及平均 surprisal；再分别加入候选单元和匹配随机单元，固定整层作为参照。冻结映射、单元和 500 句预测后，由评分端逐人计算相关。对每名隐藏参与者报告 `Δr = r(控制变量 + 候选单元) − r(控制变量)`，并列展示随机组的同一指标。人类评分只使用实际测过的原句。三个参与者逐人显示，保留负值和零增益。

## 四、五分钟 demo 怎样展示任务

主画面用一次真实 Agent 运行的可点击回放。每一步都能看到刺激、工具返回、Agent 的选择，以及**在结果揭晓之前**留下的预测。

| 时间 | 屏幕显示 | 观众能回答的问题 |
|---|---|---|
| 0:00–0:45 | 人读到的原句、模型 token、激活读取位置。切换到打乱版时标记「仅模型对照」。 | 人和模型在哪些信息上可比？ |
| 0:45–1:45 | 打开一组候选单元，查看高、低激活样例和 Agent 放弃的另一组。 | 选择是依据什么作出的？ |
| 1:45–2:45 | 显示一对仅作说明的句子：`The chef baked the fresh bread.` / `The fresh the baked chef bread.`。实际回放替换为运行样例，先展示两种解释的预测，再揭晓独立句对上的激活。 | 哪个观察会使 Agent 修改解释？ |
| 2:45–3:45 | 对同一目标词并排显示候选组消融和匹配随机消融的预测变化。 | 能定位激活的单元，是否也影响模型行为？ |
| 3:45–5:00 | 回放冻结提交，揭晓三位参与者各自的脑预测增量、随机参照和最终判断。 | 模型内部的发现，对真实人类响应有多少预测价值？ |

**首版验收**需要一份可核对的输入与分区清单、一次独立 Agent 的实际记录、同预算基线、分别展示模型干预与人脑预测的结果，以及能追溯到实际刺激的回放。即使模型侧效应清楚而脑预测增益接近零，demo 也完整：观众可以看到哪项预测成立，以及数据把脑–模型对应的结论限定到了哪里。
