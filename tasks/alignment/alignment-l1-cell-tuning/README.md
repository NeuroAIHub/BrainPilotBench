# L1 · 单神经元语义调谐

给定一组人类神经元，Agent 为每个细胞自由选择一个模型层和一个原生 MLP 单元。研究问题是在新的听句试次和新的探测词上，单元激活能否预测这个细胞偏好哪些语义域。人类听自然句，模型读固定载句 `I heard {word} today.`，对齐的观测单位是九个语义域。模型读取探测词最后一个 token 的非线性 MLP 激活。[Jamali 原研究](https://pmc.ncbi.nlm.nih.gov/articles/PMC11254762/) · [作者数据](https://doi.org/10.6084/m9.figshare.26046127.v1)

## 数据与评分

- 维护者按全局听句试次 ID 及各域内的不同模型词分别确定约 60%／20%／20% 的训练、开发和测试分区。相同试次在所有细胞中属于同一分区。一个任务实例的细胞固定，跨分区测的是同一细胞调谐的泛化。
- 入选规则只读取训练区。对每个细胞做 20 次按完整试次分半。两半各域均有至少 2 条观测且两条曲线都非常数时计为有效。至少 10 次有效且 Pearson 相关中位数 ≥ 0.30 的细胞全部入选。锁定的 Jamali v1 输入得到 16 个细胞，模型词数为 428／143／148。
- `public/words.json` 给训练词及域编号。训练 `units.npy` 轴为词、层、单元。`trials.npy` 的每行是细胞下标、试次 ID、语义域，`rates.npy` 是对应放电率。`protocol.json` 给出细胞顺序、入选可靠性和模型身份。Agent 可在训练集上自选搜索及验证方法，最多查询两套不同完整映射的开发主分。
- 对每个固定细胞，分别计算九域的平均放电率与所选单元的九域平均激活，取有符号 Pearson 相关。主分 `unit_tuning_r` 是测试细胞的等权均值，保留负值。任一细胞相关未定义时整套映射的主分未定义，开发回执为 `null`。报告同时保留逐细胞相关、选定层随机单元的期望相关、与训练相关最高策略的分差及事前预测误差。
- 两个固定策略分别为每细胞取训练相关最高的单元，以及在该策略选定的层中按固定种子随机抽一个单元。另报的同层期望使用 Agent 自己选的层，枚举该层全部相关有定义的单元。

工作区提交 `choice.json` 和 `strategy.py`。选择必须包含公开清单指纹 `packet_sha256`、完整的 `mapping` 和测试主分预测 `predicted_score`。每个映射形如 `"cell_…": {"layer": 0, "unit": 42}`，键名以本实例 `protocol.json` 为准。不同细胞可以选择同一模型单元。先提交映射与可复跑策略，再由评分器读取测试端。[准备、开发查询与隔离评分](../_multiscale/DISCOVERY.zh-CN.md) · [L1 实现](../_shared/discovery/cells.py)
