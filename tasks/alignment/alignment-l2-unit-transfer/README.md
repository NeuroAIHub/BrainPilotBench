# L2 unit selection and transfer

Choose eight native MLP units from one layer and token position to improve prediction of human language-network responses. The Agent can analyze the public Tuckute training packet and request up to two scalar development scores. It submits its final choice and a replayable selection program.

The primary metric is the mean increase in Pearson correlation over token-count and surprisal controls, computed within each participant and condition on held-out Tuckute search sentences. The scorer also reports transfer to Tuckute modify and Pereira384.

An operator stages one instance per model and researcher using `unit_transfer_cli.py prepare` and `stage`. The generated task ID is `alignment-l2-unit-transfer-<model>`. The adapters support DistilGPT2, GPT-2 small and Llama 3.2 1B. [Data, model requirements and run commands (中文)](../_multiscale/UNIT_TRANSFER.zh-CN.md)
