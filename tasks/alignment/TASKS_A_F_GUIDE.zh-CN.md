# A 到 F 任务的数据模型与评测说明

更新日期：2026-11-05。实现基准：`feat/alignment-task` 分支的 `8552479` 提交；真实数据验收记录日期为 2026-11-04。

A–F 是六个围绕脑、行为与计算模型比较的实验性 Agent 任务。它们把研究者实际会遇到的分析问题，转化成有固定输入、操作约束、提交产物和评分程序的任务。六个任务都已完成真实输入准备、参考程序运行、Docker 重跑评分和 CLI 流程验证；目前尚未纳入正式 runnable collection，也还没有独立 Agent 的能力评测结果。

当前实现与最初研究提案存在明确的范围差异：A/B 使用短段落，C/D 使用概念名称的文本表示，D 使用 EEG，E 使用派生的线性网络模拟。以下均按**当前实现**说明。完整数值契约见 [A 协议](INCREMENTAL_CONTRACT.md)和 [B–F 协议](EXPANSION_CONTRACT.md)，实测证据见[验收记录](EXPANSION_VALIDATION.md)。

## 1 这套 benchmark 在测什么

### 1.1 数据集 科学指标和 Agent 评分是三个层次

| 层次 | 含义 | 例子 |
|---|---|---|
| 人类数据集 | 真实实验记录，是分析依据 | 人阅读句子时的 fMRI、看图片时的 EEG、相似性判断、学习过程中的回答 |
| 科学指标 | 描述某个候选模型与人类数据的关系 | 脑响应预测 R²、表征相似性 RSA、行为预测 NLL、选中句子的脑响应差 |
| Agent benchmark | 指定 Agent 的工作、可见信息和评分标准 | 能否正确实现交叉验证、冻结分析窗口、重现结果，或在隐藏响应揭晓前选好刺激 |

因此，“使用 Pereira 数据”本身并不定义一个完整 benchmark。还必须规定用哪些句子和参与者、如何划分数据、拟合什么模型、允许 Agent 作哪些选择、提交什么文件，以及如何评分。同一数据集可以支持不同任务。

这里还有两个不同的“模型”：

- **被评测的 Agent**：负责读任务、写分析代码、运行工具和提交结论的系统。
- **被研究的候选模型**：例如 distilgpt2 或小型线性网络。它们提供要与人类数据比较的表示、预测或学习轨迹。

distilgpt2 在 A–F 中主要是研究材料的一部分。它的脑预测分数并不直接等于 Agent 的能力分数。

### 1.2 六个任务的研究问题与评分方向

| 任务 | 要回答的研究问题 | 当前数据与候选模型 | Agent 主评分 |
|---|---|---|---|
| [A 增量预测与替代解释](#3-任务-a-增量预测与替代解释) | 模型表示在简单刺激属性之外，还能增加多少脑响应预测能力？ | Pereira384 fMRI；distilgpt2 固定层；词数与句子在段落中的位置 | 分析正确性 `analysis_success` |
| [B 上下文依赖](#4-任务-b-上下文依赖) | 改变模型看到的前文，脑预测表现是否变化？ | Pereira384 的共同 160 个目标句；distilgpt2 三种上下文 | 分析正确性 `analysis_success` |
| [C 脑与行为联合比较](#5-任务-c-脑与行为联合比较) | 更接近脑表征的模型，是否也更接近人的相似性判断？ | THINGS IT fMRI 与三选一行为；两种 distilgpt2 概念表示 | 分析正确性 `analysis_success` |
| [D 时间分辨对应](#6-任务-d-时间分辨对应) | 两种表示与 EEG 的对应如何随时间变化，发现的窗口能否在另一分区复查？ | THINGS-EEG2；两种静态 distilgpt2 概念表示 | 分析正确性 `analysis_success` |
| [E 学习迁移与干扰](#7-任务-e-学习迁移与干扰) | 人与模型在学习新规则、返回旧规则时如何变化，学习经验是否可比？ | Holton 人类逐试次数据；单遍和重复 100 遍的线性网络 | 分析正确性 `analysis_success` |
| [F 实验刺激选择](#8-任务-f-实验刺激选择) | 根据已有训练数据，能否选出响应更强和更弱的两组句子？ | Tuckute 语言网络 fMRI；distilgpt2 特征；Agent 自选预测与选择方法 | 有效性 `selection_valid` 和隐藏响应差 `selection_effect` |

A–E 的自动评分是二元正确性检查：完整通过为 1，提交无效或执行、结果、规定解释不正确为 0。**科学结果是正、负还是不确定，都可以得到 1。** 基础设施故障单独报告，不算 Agent 得了 0。

F 是决策任务：满足约束后，按选择在真实隐藏数据上的效果给分。选择无效时不产生效果分，避免把无效提交与真实的零效果混淆。六个任务尚未定义一个统一总分；R²、RSA、NLL 和响应差不能直接相加。

### 1.3 和已有 Task1 与 Task2 的关系

仓库此前的 Task1 是 Pereira2018 官方固定层评分流程的复现，Task2 是派生的层级比较流程。A–F 是新增任务族，不是把 Task1、Task2 改名。

尤其是 A/B 的 R²，是本仓库冻结的新分析协议下的预测指标，既未做噪声上限归一化，也不等于官方 `Pereira2018.384sentences-ridge` 总分。有关旧任务的定义见 [Task1 契约](REAL_TASK1_CONTRACT.md)和 [Task2 契约](REAL_PROFILE_CONTRACT.md)。

## 2 共用的模型运行与测验流程

### 2.1 模型如何运行

A/B/C/D/F 复用本地已经下载的 distilgpt2，固定 revision 为 `2290a62682d06624634c1f46a6ad5be0f47f38aa`。它是六个 Transformer block 的预训练语言模型；此处通过本地 Python、PyTorch 和 Transformers 做前向计算，提取 768 维表示。提取时关闭梯度，不微调模型，不调用聊天 API，也不通过采样生成答案。已有验证使用 CPU。

不同任务提取的位置和上下文并不相同：

| 任务 | 模型实际接收的输入 | 保存的表示或轨迹 |
|---|---|---|
| A | 当前句子及同一短段落中此前的句子 | 最后 token 的 `transformer.h.5` 输出，沿用 Brain-Score hook，位于模型最终归一化之前 |
| B | 目标句单独、正常前文加目标句、逆序前文加目标句 | 与 A 相同的固定层和 token 位置 |
| C/D | `a photograph of <concept>`，概念名中的下划线转为空格 | 最后 token 的第一 block 表示，以及最终归一化后的末层表示 |
| F | 每个候选或训练句子独立输入，无跨句上下文 | 最后 token 的 `AutoModel.last_hidden_state`，包含最终归一化 |
| E | 刺激编号、试次顺序、当次探测特征与实际反馈 | 本地 NumPy 线性网络按试次学习，保存回答轨迹；不使用 distilgpt2 |

A/B 的末层 hook 与 C/D/F 的最终归一化表示不能直接当作同一份特征。C/D 的模型输入是概念名称，实际图片并没有送入 distilgpt2。

特征提取和 E 的网络模拟属于数据准备阶段，由任务维护者完成。正式 Agent 工作区主要收到冻结的数值数组与元数据，Agent 编写分析或选择程序；提交重跑不需要下载模型，也不需要 GPU。当前 A–F 不依赖 Llama-3.2，Llama 下载仍按此前决定暂缓。

### 2.2 一次测验经过哪些步骤

1. **维护者准备输入。** 下载并核验官方数据，记录版本和哈希，完成预处理、身份匹配、特征提取及固定划分，生成带 manifest 的输入包。
2. **Agent 阅读任务并声明计划。** 根据允许的选择填写 `submission/plan.json`，写明理由；例如 A 选控制变量，C/D 选比较顺序，E 选分析窗口大小。
3. **Agent 实现与执行。** 编写 `submission/analyze.py --inputs DIR --output DIR`，产生计划副本、数值结果、结构化结论及报告。
4. **维护者收集并重跑。** 在隔离 Docker 中用相同公开输入重新执行提交源码，检查保存产物与重跑产物是否一致。
5. **按任务评分。** A–E 对照可信重计算结果；F 在冻结选择后使用维护者持有的隐藏响应计算效果。

默认重跑环境限制为 2 CPU、8 GiB 内存和 900 秒，禁网，以非 root 用户执行，输入及源码只读。这些是当前执行配置，尚未完成跨 Agent 的资源校准。**CLI 的 manual 模式不会自动隔离 Agent 的开发过程**；实际评测时还需单独限制 Agent 对维护者目录、参考答案和 F 隐藏数据的访问。

### 2.3 输出检查覆盖什么

共用提交包含分析计划、`results/summary.json`、任务专用数组、`conclusion.json` 和 `report.md`。A 还要求完整预测及折内调参诊断，B–E 同样检查各自规定的详细数组。A–E 数值比较容差为绝对误差 `1e-7` 加相对误差 `1e-5`；数组身份、结构化结论和重跑一致性也必须通过。

报告和理由必须存在，但**自由文本的科学质量没有自动打分**。例如，把 `causal_effect_established` 错写为真会失败；如果错误论断只藏在自由文本里，当前检查并不保证能发现。固定脚本已经可以通过 A–E，因此现阶段通过意味着完成了受限的分析执行和规定解释检查，不能直接证明开放式科研创新能力。

## 3 任务 A 增量预测与替代解释

任务 ID：`alignment-incremental-explanation`。协议：`pereira384-incremental-ridge-v2`。

### 3.1 研究问题与数据

一个模型能预测脑响应，可能因为它表达了有用的语言信息，也可能部分因为它携带了句子长度、段落位置等较简单的属性。A 要求把这些可计算的替代解释显式放进模型，检验加入语言模型表示后是否还有预测增量。这里的“增量解释”是预测意义上的增量，不是已识别的因果贡献。

使用 Pereira2018.language 中包含 384 个句子的子集。原始研究包含句子阅读时的脑成像测量；本任务复用经 Brain-Score 整理并验证的缓存。[Pereira 等原始论文](https://www.nature.com/articles/s41467-018-03068-4)提供实验来源，当前分析定义则以 [A 协议](INCREMENTAL_CONTRACT.md)为准。

当前包包含：

- 384 个句子，组成 96 个四句短段落，归入 24 个主题组。
- 9 名参与者，12,137 个保留的神经测量列。此处 neuroid 是测量单元标识，不能理解为记录了 12,137 个单神经元。
- 每句 768 维固定模型特征、词数、在段落中的第 1–4 句位置，以及句子、段落、主题组和参与者 ID。

源数据原有 12,155 列；维护者在准备时剔除了 18 个全零列并记录 ID。这是使用整个供给数据集进行的目标质量控制，不是仅在训练集上做的特征筛选。上游字段 `story` 在这份数据中表示主题类别，并非一篇连续长故事。

### 3.2 Agent 要完成的比较

Agent 从三个控制集选择一个并解释理由：空白分词词数、四个段落位置指示变量，或者两者一起。词数不是 tokenizer 的 token 数，也不是语速。

对同样的样本和数据划分，分别拟合三个岭回归读出：

| 读出 | 输入 | 回答的问题 |
|---|---|---|
| control | 控制变量 C | 简单属性本身能预测多少？ |
| model | 固定表示 X | 模型表示本身能预测多少？ |
| joint | C 与 X 拼接 | 加入模型表示后能预测多少？ |

“读出”是从模型特征映射到脑测量的回归模型；拟合它不等于微调 distilgpt2。

### 3.3 怎么测验与计算

采用按主题组划分的嵌套交叉验证：外层 5 折负责测量未参与拟合的主题组上的预测表现，内层 3 折只在外层训练数据中选择正则化强度。外层种子为 41，内层种子为 `42 + 外层折编号`，输入中的 `splits.json` 固定具体身份划分。

所有标准化都只使用当前训练分区的均值和总体标准差；Y 只按训练均值中心化，截距不受惩罚。每种读出从 `[0.1, 1, 10, 100, 1000, 10000, 100000, 1000000]` 独立选择一个共享 alpha，内层评分并列时选最小值。不能先用整个数据集拟合标准化，也不能用外层测试响应挑 alpha。

每个测量列的 R² 为：

```text
R² = 1 − 所有外层留出预测的平方误差之和
         / 每个留出样本相对其对应外层训练均值的平方偏差之和
```

先在同一参与者内平均测量列，再对参与者等权平均。不能把所有人的测量列混在一起平均，也不能把不同折的 R² 简单平均来代替上述合并计算。负分保留，不做噪声上限归一化。

主要科学比较为 `ΔR² = R²_joint − R²_control`。用同一套主题组重采样对三个读出做配对 bootstrap，共 1,000 次，取 2.5% 和 97.5% 分位数。这个区间固定了已经拟合的折外预测，**不包含重新训练带来的不确定性**，属于描述性的条件区间。

### 3.4 Benchmark 评分与 Agent 能力

评分核对完整折外预测、身份顺序、每折 alpha 及内层分数、汇总值和规定结论。正确的负增量或跨零区间可以得满分，声称“已排除全部混杂”或“证明因果贡献”会违反结构化结论要求。

它针对的能力包括：把替代解释转成可计算控制变量、执行无泄漏的训练和验证、按参与者正确汇总、区分预测证据与因果解释。理由质量和是否主动发现了协议之外的重要混杂，仍需人工评阅。重跑与结果一致也不构成对任意源码“从未读取测试响应”的形式证明；这里全部分析响应对 Agent 可见。

### 3.5 当前参考结果与解释

采用“词数加位置”时：

| 指标 | 参考值 |
|---|---:|
| 控制读出 R² | 0.008715 |
| 模型读出 R² | 0.016253 |
| 联合读出 R² | 0.016718 |
| 联合减控制 ΔR² | 0.008003 |
| 条件描述区间 | [-0.001602, 0.017617] |

点估计为正，但区间跨零，当前分析没有建立稳健的正增量结论，也没有证明两者等价。该结果只针对已观测参与者中的留出主题组，不检验新参与者泛化。

当前 v2 的 alpha 网格是在开发阶段发现旧网格最优值总落在上界后扩展的。两版都属于对已检查公开数据的探索性分析，v2 结果不能包装成独立确认。参考程序 `analysis_success=1`；数值正确但结构化结论虚称因果效应的提交被判为 0。

## 4 任务 B 上下文依赖

任务 ID：`alignment-context-dependence`。协议：`pereira384-context-v2`。

### 4.1 研究问题与实际样本

B 问的是：同一目标句的模型表示，在有无前文、前文顺序不同时，对原有脑响应的预测能力是否变化？它检验当前模型的短上下文依赖，不直接检验长期记忆。

沿用 A 的 Pereira 数据、9 名参与者、12,137 个神经测量列及同一固定层。只选每个四句段落的第 3、4 句，使逆序前文确实改变顺序：原有 192 个候选目标，剔除正常与逆序前文 token 数不相等的 32 个，最终三个条件共同使用 160 个目标句和 24 个主题组。排除条件只依赖文本与 tokenizer，不依赖脑响应。

### 4.2 模型输入如何改变

以一个四句段落 `s1、s2、s3、s4` 的最后一句为目标：

| 条件 | 输入 |
|---|---|
| sentence_only | `s4` |
| normal_prefix | `s1 → s2 → s3 → s4` |
| reversed_prefix | `s3 → s2 → s1 → s4` |

目标句始终放在最后，没有使用未来句子。正常与逆序条件包含相同的历史句子集合，并匹配 token 总数；目标句单独条件本来就更短，不与前两者强求长度一致。

逆序改变了所有前文顺序，也改变了离目标最近的句子，因此它不是“只破坏远距离历史、保持最近上下文”的实验。特征准备验证了正常前文特征与原缓存完全一致，最大绝对差为 0；最长输入 77 tokens，无截断。

### 4.3 怎么测验与评分

Agent 对三个条件分别执行 A 中的嵌套岭回归，保持共同目标、外层划分、调参规则和聚合方式一致；每个条件独立在训练数据中选 alpha。

报告两个比较：正常前文减目标句单独，以及正常前文减逆序前文。两者都用 1,000 次配对主题组 bootstrap 计算基于固定折外预测的条件描述区间，并提交所有条件的完整预测和调参记录。

`analysis_success` 检查计算和结构化解释。人类脑响应没有在三种上下文下重新采集，因此结论必须承认这是**只改变模型输入**的比较，不能声称已经验证相同的人类上下文干预效应。

### 4.4 考察能力与当前结果

B 针对的是构造可比较条件、检查身份和 token 数、排除未来信息、保持统计读出一致，以及限制结论范围的能力。当前上下文特征已经由维护者准备，自动评分主要检验分析执行；它没有完整测验 Agent 自行发明上下文干预或重新提取特征的能力。

| 比较 | ΔR² | 条件描述区间 |
|---|---:|---|
| 正常前文 − 目标句单独 | 0.000621 | [-0.003033, 0.004278] |
| 正常前文 − 逆序前文 | 0.000382 | [-0.000309, 0.001165] |

三个条件的 R² 分别为：目标句单独 0.007674、正常前文 0.008295、逆序前文 0.007913。两项比较的区间都跨零。参考程序仍得到 1；“没有明确优势”是有效结果。这个短段落实例不能回答长故事理解、长期记忆或者人脑对上下文顺序的因果反应。

## 5 任务 C 脑与行为联合比较

任务 ID：`alignment-brain-behavior`。协议：`things-brain-behavior-v1`。

### 5.1 研究问题与数据来源

如果一种表示更接近脑活动中的对象关系，它是否也更接近人主观判断的对象关系？C 把“与脑相似”和“与行为相似”分别测量，再比较模型排名，避免把一个指标的优势自动推广到另一个指标。

脑数据来自 THINGS 的 IT 区域 fMRI 测试集衍生数据，行为数据来自 THINGS 的 odd-one-out 判断。行为实验让人从三张对象图片中选出最不相似的一张，剩下两张就构成该次选择中的相似对。实验来源见 [THINGS-data 论文](https://elifesciences.org/articles/82580)，具体输入来自 [IT 衍生数据](https://api.figshare.com/v2/articles/23284622)和[行为数据](https://osf.io/f5rn6/)。

当前实际使用：

- 3 名 fMRI 参与者、100 张测试图片，每图每人 12 次重复；每个概念对应一张测试图。
- IT，即下颞皮层区域的响应。先对每人每图的重复测量求平均，再计算图片两两之间的脑表征差异。
- 与这些概念匹配的三元组行为选择；行为参与者与 fMRI 参与者不同，图片实例也不保证相同。

因此，这是概念层面的跨数据集比较，不能解释成同一人脑响应与其行为之间的个体相关。

### 5.2 比较什么模型

把每个概念写成 `a photograph of <concept>` 输入 distilgpt2，取第一 block 和最终归一化末层的表示，得到两个固定候选。

它们是关于对象名称的语言表示。例如人看到某张猫的照片，模型收到的是包含猫这一概念的文字提示。模型没有看见照片像素，因此结果涉及语义概念代理与人类数据的对应，不能宣称评测了视觉模型对同一图片的表征。

### 5.3 怎么测验

先按概念 ID 排序，以种子 41 打乱后划分为 40 个训练概念、30 个发现概念、30 个确认概念。每条行为三元组只有在三个概念全属于同一分区时才保留。当前最终只剩 **44、16、17** 条训练、发现、确认行为判断；原始行为数据规模很大，不代表当前这个交集实例也有充分样本。

Agent 在计划中声明两个候选的比较顺序，然后完成两个互相独立的指标：

**脑指标 RSA。** RDM 是“表征不相似性矩阵”：每个格子表示两个概念在某种表示中有多不同。模型使用余弦距离；脑数据使用响应向量的相关距离。取同一概念分区内两个 RDM 的上三角，用 Spearman 秩相关衡量它们是否对相似与不相似的对象给出一致排序，再对三名参与者等权平均。RSA 越大，表示关系的对应越强，但不表示单位一一对应或计算机制相同。

**行为指标 NLL。** 对每个三元组，用三对概念的负距离经 softmax 得到三种“相似对”的预测概率。温度参数决定概率有多尖锐，只能在训练三元组上从 `[0.01, 0.1, 1, 10, 100]` 选择，再冻结用于发现和确认分区。

```text
某相似对的预测概率 ∝ exp(−该对的距离 / 温度)
NLL = −log(人实际选中的相似对的预测概率)，再对试次平均
```

NLL 越低越好。它衡量对真实行为的概率预测，不是简单的分类命中率，也不拟合人的脑响应。

两个比较差值统一为“正数有利于第一个候选”：脑指标用第一个减第二个 RSA，行为指标用第二个减第一个 NLL。两者同号记为同方向，异号记为相反方向；这只是描述性排名，不自动表示显著差异。

不确定性使用逐概念删除 jackknife：每次删去一个概念及所有包含它的行为三元组，重新计算差值，温度保持训练时选定的值。这样不会把共享概念的 RDM 格子或三元组误当成独立样本。输出是描述性标准误，不是已校准的人群结论。

### 5.4 Benchmark 评分与 Agent 能力

`analysis_success` 核对温度、分区、逐试次 NLL、逐参与者 RSA、排名方向、jackknife 标准误与规定解释。Agent 不需要使两个排名一致，也不需要证明它们不同。

任务针对的是跨模态身份匹配、训练与确认数据分离、不同指标方向的处理，以及面对脑和行为证据不一致时的判断能力。一个具体数据陷阱是：作者的 `trainset.txt` 已经转换为排好序的零基概念索引，再应用一次 `sortind` 会把概念身份配错。当前维护者已完成这一步准备，Agent 必须保持输入身份，但其自行发现原始索引错误的能力尚未由这个固定输入实例充分测到。

另外，当前划分是从作者公开行为训练表重新按概念切分，不能冒称使用了作者原版 benchmark 的官方测试划分。

### 5.5 当前参考结果与解释

| 候选 | 确认集脑 RSA，越高越好 | 确认集行为 NLL，越低越好 |
|---|---:|---:|
| distilgpt2 第一 block | 0.023667 | 1.014559 |
| distilgpt2 最终归一化末层 | 0.034142 | 1.090559 |

末层的脑 RSA 较高，第一 block 的行为 NLL 较低，描述性排名相反。但脑差值约为 -0.010475，其 jackknife 标准误约 0.078821；行为差值约为 0.076000，标准误约 0.159633。确认行为样本只有 17 条，不能据此断言存在可靠的人群层面的脑—行为分离。

两个温度为 0.1 和 0.01，后者处于允许网格的下界，不能称为无约束情况下的全局最优温度。参考程序得 1，超出证据的结构化结论被拒绝。

## 6 任务 D 时间分辨对应

任务 ID：`alignment-temporal-correspondence`。协议：`things-eeg2-temporal-v1`。

### 6.1 研究问题与数据

D 在每个时间点测量模型表示与脑响应的对应，并要求把发现阶段选出的时间窗口固定下来，在另一组参与者和概念上复查。它面对的是研究者常见的问题：一条曲线上很多点都能比较，怎样避免看到哪个时间段好看就只报告哪个？

实际数据是 **THINGS-EEG2 脑电数据**，不是最初提案中的 MEG 脑磁数据。来源为 [Gifford 等的数据项目](https://osf.io/3jk45/)及[作者处理代码](https://github.com/gifale95/eeg_encoding/tree/101997d4f14c41b615bcaf8c0907740106d260c5)；使用的具体子集和处理边界已记录在[验收记录](EXPANSION_VALIDATION.md)。

当前包含参与者 01、02，共 200 张测试图，每图 80 次重复，17 个后部 EEG 通道；采样率 100 Hz，完整时间轴为刺激出现前 200 ms 至出现后 790 ms，共 100 个采样点。维护者先平均重复测量，形成 `2 × 200 × 17 × 100` 的响应数组。

采用作者发布的预处理结果：含 -200 至 0 ms 基线校正和每个 session 的多变量噪声归一化。该归一化的协方差估计使用了作者原始训练与测试分区。因此当前分析是**以这些发布衍生数据为条件**的比较，不能声称从原始 EEG 开始实现了完全只用训练数据的预处理。

### 6.2 模型与发现确认划分

模型与 C 一样，是 distilgpt2 对概念文字提示的第一 block 与最终归一化末层表示。它们都是静态向量；这里没有让模型按脑电时间轴动态演化，也没有规定第几层就对应多少毫秒。

将 200 个概念按固定种子划分为两组，各 100 个：

- 发现分区只用参与者 01 和第一组概念。
- 确认分区只用参与者 02 和第二组概念。

两者参与者和概念均不重叠，但仍是公开数据的探索性重用，不是新增的人体实验或前瞻性确认队列。确认数据在分析包中可见；协议要求程序只从发现分区选窗口，不等同于把确认结果从 Agent 的整个开发过程里隐藏。

### 6.3 怎么测验

每个时间点都对 EEG 通道响应计算概念间相关距离 RDM，与模型余弦距离 RDM 做上三角 Spearman RSA，提交完整时间曲线，包括刺激出现前的基线。

Agent 声明候选比较顺序后，在发现分区的七个窗口中选择：`[0,50)`、`[50,100)`、`[100,150)`、`[150,200)`、`[200,250)`、`[250,300)`、`[300,350)` ms。选择标准是第一个候选减第二个候选的窗口平均 RSA **有符号差值最大**，不是绝对差最大；并列时选最早窗口。随后在确认分区原样使用该窗口。

确认阶段进行 499 次刺激标签置换，种子为 73。每次对所有模型、时间点和参与者使用同一标签置换，保留比较中的依赖结构。生成两类参照：

1. 每次置换在所有候选和完整时间轴上取最大绝对 RSA，用来给每个时间点计算经过多重比较校正的 p 值。
2. 在已经冻结的窗口内，保存两候选的差值，用双侧绝对差构造窗口的标签置换 p 值。

两类 p 值都采用 `(1 + 更极端的置换次数) / 500`。第二项的零假设是共同重排刺激身份下没有对应关系，**不是两个模型在人群中的表现相等**；不能把它当成一个通用的模型优越性检验。

### 6.4 Benchmark 评分与 Agent 能力

评分检查完整曲线、真实时间轴、发现阶段的七个窗口分数、冻结窗口、置换统计量和校正 p 值，不能只提交最好看的峰值或一张图。

它针对时间轴处理、独立划分、避免循环分析、多重比较控制和零假设解释的能力。典型错误包括把毫秒和秒混淆、删掉基线、在确认曲线上重新挑窗口、每个时间点分别随机化而破坏依赖，以及把 Transformer 层深直接当成脑潜伏期。

这些错误若改变规定数组或结构化结论会被拒绝。自由文本中的更深层科学论证仍需人工检查。

### 6.5 当前参考结果与解释

发现阶段选中 `[150,200)` ms。确认分区中第一 block 减末层的平均 RSA 差为 **0.057990**，对应标签置换 p 值为 **0.116**，未在 0.05 阈值下拒绝该零假设。

参考程序得到 `analysis_success=1`。这个结果没有建立精确的效应起始时刻、共享的动态机制或人群层面的模型优越性。当前只有两名 EEG 参与者，且每个分区实际只有一人，不能将内部划分误当成充分的人群验证。

## 7 任务 E 学习迁移与干扰

任务 ID：`alignment-learning-transfer`。协议：`human-ann-transfer-v1`。

### 7.1 研究问题与人类数据

学完规则 A，再学规则 B，会不会更容易学会 B？返回 A 时，原有表现会不会变差？这分别涉及迁移与干扰。要比较人和模型，除了曲线像不像，还必须核对它们经历了多少试次、获得了什么反馈，以及换任务时是否保留状态。

数据来自 Holton 等的连续学习研究及[作者公开代码和处理后数据](https://github.com/eleanorholton/transfer-interference/tree/dcd451046759ebbbfa2987031a64da8c773e750d)。原研究把人与网络在规则相同、相近、相远条件下的学习和重测表现进行比较；这些条件及研究动机见[原始论文](https://www.nature.com/articles/s41562-025-02318-y)。当前 benchmark 另行冻结了一个小型分析子集与派生模拟协议。

当前选取 2 项 study × 3 个条件 × 每组 3 人，共 **18 人**，每个 same/near/far 条件合计 6 人。选择依据是参与者 ID 的字典序，不依据表现好坏；这仍是有限的便利子集，不能视为代表性人群样本。

每个人都有 `A1 → B → A2` 三个阶段：先学习 A，转到 B，再返回 A。每阶段 120 个有序事件，其中 60 次探测 feature 1。源表包含刺激编号、当前探测特征、目标角度、人的回答、实际含噪声反馈及反馈是否存在。人的回答与目标以弧度保存。

本任务分析所有有效的 feature-1 回答，**包括没有反馈的回答**，尤其是 A2 的重测；不能因为某次没有反馈，就把该次测量从误差分析中删掉。这里没有 fMRI 或 EEG 数据。

### 7.2 使用什么学习模型

维护者用 NumPy 生成两条派生模型轨迹，均为 `12 → 50 → 4` 线性网络：

- 输入是 12 种刺激的 one-hot 编码。
- 中间层 50 个单元，无偏置、无非线性激活。
- 输出 4 个坐标，表示两个待探测特征各自的 sin/cos；每次只对被探测特征作答和更新。
- 权重用标准差 0.001 的零均值正态分布初始化；每人使用由其 ID 哈希确定的随机种子，两个重复条件使用相同的初始化规则。
- SGD 学习率为 0.1，损失为当前被探测的两个坐标的均方误差。

| 模型 | 每阶段经历 | 与人的事件和反馈次数是否匹配 |
|---|---|---|
| `linear50_feedback_once` | 人的完整阶段序列执行 1 遍 | 匹配 |
| `linear50_feedback_replay100` | 人的完整阶段序列重复 100 遍 | 不匹配 |

两者都先预测再更新，只在当次真实含噪声反馈存在时更新；不把无反馈试次的目标值或人的回答偷偷当作训练标签。阶段之间保留权重，不打乱试次顺序。重复 100 遍是每个阶段的整个序列重复 100 遍后，再进入下一阶段。

架构参考作者代码，但这里的初始化、监督目标和学习率由本任务另行规定。它们是**派生基线**，不能称为原论文模拟的精确复现。事件和反馈次数相同也只证明这一层面的经验匹配，不表示人和模型拥有完全相同的主观经验或学习规则。

### 7.3 怎么测验与计算

Agent 在计划里选择 `W=20` 或 `W=40`，以每阶段最初和最后 W 次 feature-1 回答计算指标。先用圆周误差处理角度：179° 与 -179° 的距离是 2°，不是 358°。

```text
误差 = abs(wrap(回答角度 − 目标角度, −π, π)) × 180/π
```

令 `early(A1)` 为 A1 最初 W 次的平均误差，`late(A1)` 为最后 W 次的平均误差，其余阶段同理：

| 指标 | 定义 | 正值的含义 |
|---|---|---|
| 初始阶段差 | early(A1) − early(B) | B 初始误差更低；只是描述性迁移相关比较 |
| 切换代价 | early(B) − late(A1) | 切到 B 后误差增加 |
| 干扰 | early(A2) − late(A1) | 返回 A 时比先前结束 A 时更差 |
| A1 内学习 | early(A1) − late(A1) | A1 内误差下降 |
| B 内学习 | early(B) − late(B) | B 内误差下降 |
| A2 内变化 | early(A2) − late(A2) | A2 内误差下降，不自动代表由反馈引起的学习 |

初始阶段差不能单独识别“先学 A 对 B 的因果帮助”，因为它没有另设一个未经 A 学习的 B 对照组。人每阶段只有 60 个相关回答，W=40 时前后窗口重叠，不能把它们当作独立样本。

还需把各系统每阶段的完整回答序列等分为 10 个连续 bin，输出误差曲线。单遍模型每阶段有 60 个 feature-1 回答，重复模型有 6,000 个；这十段表示**相对阶段进度**，不代表相同训练次数。

先按参与者计算指标，再在 same/near/far 条件内等权平均，计算模型减人的差值；每个条件内做 1,000 次配对参与者 bootstrap，同一参与者对应其模型轨迹，种子为 73。输出的百分位区间是小样本的描述性区间。

### 7.4 Benchmark 评分与 Agent 能力

Agent 要提交全部参与者的六项指标、完整分箱曲线、模型减人的比较和区间，以及经验审计：每阶段重复次数、反馈更新次数、状态是否保留、是否在无反馈时更新、经验次数是否匹配。

`analysis_success` 衡量这些结果和结构化结论是否正确，而不是人和模型的曲线必须接近。一次重要能力检验是：Agent 能否识别“曲线更好看，但模型额外训练了很多遍”这一不可忽略的比较条件。

任务还针对逐试次因果顺序、反馈可用性、环形变量处理和配对统计。当前网络轨迹由维护者预先生成，因此它直接评测轨迹分析与经验审计，没有要求 Agent 从零实现或发现新的学习算法。此数据也不能证明相同脑机制，或回答跨天记忆巩固问题。

### 7.5 当前参考结果与解释

参考分析采用 W=20，正确识别单遍模型经验次数匹配、重复 100 遍模型不匹配。以“干扰”这一项为例，单位为角度，数值为各条件内 6 人或其配对模型的平均值：

| 条件 | 人 | 单遍模型 | 重复 100 遍模型 |
|---|---:|---:|---:|
| same | 0.230° | 5.146° | 0.483° |
| near | 4.454° | 9.534° | 16.930° |
| far | 30.337° | 43.897° | 50.883° |

这只是当前 18 人子集及指定模拟的描述性结果，并非原论文全体样本的结果，也不意味着所有学习指标都给出相同模式。评分还核对其他五项指标、配对区间和曲线。完整参考产物位置见文末证据入口；参考程序得到 1，超出行为证据的结构化机制主张被拒绝。

## 8 任务 F 实验刺激选择

任务 ID：`alignment-stimulus-selection`。协议：`language-stimulus-selection-v1`。

### 8.1 研究问题与人类数据

F 要求 Agent 用已有句子和脑响应学习一个选择策略，再从候选池中选出预计能产生较强与较弱响应的句子。它把分析转成一个需要在结果揭晓前作出的决策。

科学来源是 Tuckute 等的研究：作者先拟合句子到语言网络响应的编码模型，再选择预计增强或抑制响应的新句子，在其他参与者中测量。[原始论文](https://www.nature.com/articles/s41562-023-01783-7)描述了这个真实实验；本任务使用其[公开数据](https://osf.io/ru38b/)和[作者代码](https://github.com/gretatuckute/drive_suppress_brains/tree/7175a12dc25f8765e2fb2196d71c2ea98e97604b)构建离线候选池。

当前使用左半球语言网络 ROI 响应。作者先在每个 session 内对体素响应做 z 标准化，再在 ROI 内平均；效果单位是这套作者归一化后的响应单位，不是原始 BOLD 信号百分比。

| 分区 | 当前规模 | Agent 能看到什么 |
|---|---|---|
| 训练 | 988 个句子 × 5 名参与者 | 句子、模型特征、每位训练参与者的脑响应 |
| 候选 | 500 个句子 × 3 名其他参与者 | 句子、模型特征、不含响应含义的 ID、词长分箱；看不到响应 |

训练源本来有 1,000 个句子，12 句缺少一名训练参与者的响应，因此排除，未填补缺失值。候选参与者测过的句子并不完全重合，准备程序选择共同覆盖的 500 句、3 人池。训练与候选的句子、文本和参与者均不重叠。

公开包移除了候选响应、作者 drive/suppress 条件标签、作者预测值和响应衍生元数据；候选按不透明 ID 排序，避免行顺序泄露原条件。这些是公开实验数据，隔离工作区仍不能证明被评测 Agent 的预训练记忆中不存在标签。

### 8.2 模型和 Agent 的自由度

每个句子独立输入本地 distilgpt2，使用最终归一化末层的最后 token 特征。这里复用小模型缓存，不复现原研究中更大语言模型的完整选句系统。

Agent 可以自选如何从训练特征预测响应，也可以自选候选选择策略。它必须为全部 500 个候选提交一个有限的浮点预测值，并选出：

- 10 个唯一的 drive 句子，预计响应较高。
- 10 个唯一的 suppress 句子，预计响应较低。
- 两组不重叠，且各自满足相同的词长分箱配额。

协议定义的词数区间为 `[0,10)`、`[10,15)`、`[15,20)`、`[20,∞)`，配额由输入元数据固定。**当前 500 句实际都为 6–8 个词，全部处于第一个箱。** 因此当前实例约束的是同一粗粒度长度箱中的选择，并没有做到逐词数精确匹配，也没有真正检验多个长度箱之间的分配。

选择不必与参考岭回归相同，程序也不要求严格按提交预测的前十、后十选取。预测和最终选择都必须可重跑，策略理由留在报告中供解释与审阅。

### 8.3 如何冻结与测验

Agent 在获得候选真实效果前提交计划、源代码、全部预测和两组 ID。维护者先把输入版本、隐藏数据版本、源码、计划、预测与选择的指纹写入绑定 Agent 身份的 ledger，再揭晓效果。

同一个冻结提交可以重复执行；针对同一包改源码、改预测或改选择后再次查询效果会被拒绝。维护者必须跨运行复用分配给该 Agent 的 ledger，并把 ledger 与隐藏数据放在 Agent 无法访问的目录。任意创建新 ledger 会绕过次数限制，所以这项约束需要部署方落实，不能只依赖一次 CLI 命令。

评分分两步：先验证源码重跑、预测一致性和选择约束，再使用隐藏响应计算：

```text
每位隐藏参与者的效果 = 所选 10 个 drive 句子的平均响应
                       − 所选 10 个 suppress 句子的平均响应

selection_effect = 三位隐藏参与者效果的等权平均
```

`selection_valid=1` 表示提交满足约束；`selection_effect` 保留正负号，越大越符合选择目标。有效但负效果的提交仍有一个真实的负分。无效选择，例如两组重叠，不产生效果分；环境启动失败则属于基础设施故障。

### 8.4 对照基线与考察的能力

维护者提供两个参照：固定岭回归和同预算随机选择。固定岭回归只用训练数据标准化，alpha 固定为 100，以五名训练参与者的平均响应为目标，在各词长箱内按预测选两端；随机参照做 1,000 次同样满足配额、两组不重叠的选择，种子为 73。

F 直接考察根据已有证据作预测决策、在有限刺激预算下选择样本、从训练参与者泛化到未见参与者，以及在揭晓答案前冻结实验方案的能力。它的效果评分对不同策略开放，因此与 A–E 的固定分析正确性有明显区别。

当前候选都是已有真实测量的句子，Agent 不能自由生成新句子后要求新增人类实验。最终高分表示在这个离线池和观测参与者中选择有效，尚不能直接推广为新的刺激生成能力或前瞻性人体实验成功。

### 8.5 当前参考结果与解释

固定岭回归参考选择的平均隐藏响应差为 **0.347353**；三名隐藏参与者的差值分别约为 0.151220、0.218468 和 0.672371。

同预算随机选择的均值约为 0.001366，2.5%–97.5% 分位范围为 `[-0.428121, 0.417675]`；参考选择约位于随机分布第 94 百分位。这个百分位不是人群显著性 p 值，也不是一次新人体干预的证据。

参考提交通过有效性检查并获得上述效果分。真实 Docker 检查拒绝了 drive/suppress 重叠的提交；同一 ledger 下更换源码再次查询也被拒绝；完全相同的冻结提交可正常重跑。

## 9 六个任务对 Agent 能力的覆盖

### 9.1 研究工作与当前自动测量的对应

| 任务 | 研究者面对的实际工作 | 当前可直接检查的表现 | 还不能凭当前得分确认的能力 |
|---|---|---|---|
| A | 排查简单属性是否解释了模型优势 | 按声明的控制集正确计算增量，避免错误聚合，遵守结论范围 | 主动发现所有重要混杂、提出新的因果识别方案 |
| B | 构造公平的上下文比较 | 在相同目标和划分上比较三条件，正确解释区间 | 自行设计完整上下文实验、理解长期记忆机制 |
| C | 联合不同模态的证据 | 保持概念身份和分区，训练内校准行为模型，正确比较排名和不确定性 | 完成任意原始数据清洗、证明普遍的脑—行为统一或分离 |
| D | 分析时间曲线并控制选择偏差 | 保留时间轴，按发现分区选窗口，冻结确认和多重比较计算 | 从曲线识别精确脑机制、把模型深度映射为生理时间 |
| E | 比较人的学习与模型学习 | 按试次、反馈和状态计算轨迹，识别经验次数差异 | 自主发现学习算法、证明与人相同的神经机制 |
| F | 根据预测选择下一批实验刺激 | 合法冻结选择，并在隐藏响应上取得实际效果 | 在无限新刺激空间中生成有效材料、组织新增人体实验 |

这些问题来自真实研究工作；**具体的六项 Agent 题目、输入子集、切分、输出格式和评分程序是本项目设计的**，不是原论文作者已经发布的六个 Agent benchmark。真实性来自数据与研究问题，标准化来自本项目对工作范围的约束，两者应分别评估。

### 9.2 通过任务意味着什么

对 A–E，一次通过最直接支持的是：在给定数据、明确协议和环境约束下，提交的分析产物与可信实现一致，而且代码能重跑、规定的结论边界被遵守。固定脚本可以完成这一点，所以不能仅凭 1 分区分“严格按规范执行”与“独立理解后设计了研究”。

对 F，有效选择的效果进一步反映了 Agent 在隐藏目标上的决策质量。不过只有单个固定池、三个隐藏参与者，也存在公开数据污染风险，尚不能将一次高效果泛化为广泛的实验设计能力。

A–E 的分析数据可见；计划文件是分析声明，不是证明结果揭晓前完成的预注册。C/D 的发现和确认划分约束计算过程，也不能抹去公开数据已被检查过的事实。F 在揭晓隐藏效果前冻结提交，拥有更明确的决策评估边界，但仍依赖实际部署隔离和 ledger 管理。

### 9.3 什么仍需独立验收

后续能力结论需要实际独立 Agent 的运行证据，而不能沿用维护者脚本的标签。至少应区分协议遵循、数值正确、自由文本科学判断和开放策略表现；前两项已有自动检查，后两项只有部分覆盖。

正式推广还需要科学评阅与更强实例：例如 B 的长故事数据、C 更多确认行为判断及真正的图像特征、D 更多参与者，以及跨实例的资源和分数校准。这些是当前 benchmark 的范围边界，并非已经实现的功能。
