# L3 · 注意力头到下游 MLP 的路径发现

Agent 在冻结模型内自由选择发送层、一个注意力头、任意更深的接收层和该层 8 个原生 MLP 单元。输入为 Tuckute 原句和仅反转中间词序的配对。配对保留词集合、目标词首 token 及其位置。前向计算只给模型目标词之前的前缀。[Tuckute 作者数据](https://github.com/gretatuckute/drive_suppress_brains) · [路径替换方法](https://arxiv.org/abs/2304.05969)

## 公开探索与确认

- 公开 64 对基线句及 5 位训练参与者在原句上的脑响应。开发 32 对、盲测 64 对，增强和抑制各半。原句及其改写作为一组，三个分区的句族互斥。开发只返回路径主分，脑侧确认使用另外两位参与者在测试原句上的实测响应。
- `training_gain_proxy.npy` 的轴为训练折、层对、发送头、接收单元。每个值是将该头从乱序状态换为原句状态后，该接收单元的激活变化乘以乱序目标 log 概率对它的梯度，再在该折取均值。四个训练折由公开行号模 4 决定。Agent 可检查折间稳定性、跨头比较、自由组合单元，也可结合 `train_units.npy`（句子、层、单元）和 `brain.npy`（句子、参与者）。训练近似用于生成候选，正式分数由完整的非线性前向干预计算。
- 可在训练句上反复发起精确干预，读取整体平均增益和四折各自的增益，用于检验近似误差和比较替代路径。训练回执按 actor 登记并随代码冻结，独立于两次开发额度。
- 开发和盲测时，仅将选定头在末词之前最后一个位置对下游接收层残差的贡献替换成原句贡献。重新计算所选 8 个单元，将这 8 个单元的输出变化注入乱序前向过程。对同层每个其他头重复相同干预，接收单元始终相同。
- 主分 `path_specific_gain`（nat）为所选头恢复的目标词 log 概率减去其他头的平均恢复量，再对留出句对取均值。基线为公开梯度近似最大的路径和固定种子随机路径。报告给出原句与乱序句的完整差距、各项恢复量、与训练基线的分差和事前预测误差。
- 脑侧辅助分 `brain_delta_r` 在原句上测量。在训练原句上用所选 8 个完整单元的激活拟合固定岭回归（标准化后 α=100），预测训练参与者的平均响应。用同一读出分别处理完整模型和去掉指定头对接收单元直接贡献的模型。在两位留出参与者、两种条件内分别计算完整相关减去切断后的相关，再等权平均。测到的因果作用发生在模型内，人脑端提供独立的预测目标。

工作区提交 `choice.json` 和 `strategy.py`。选择包含 `packet_sha256`、`path`、`predicted_score`（nat，可为负数）和 `falsifier`（什么观察将推翻解释，1–500 字符）。路径形如 `{"sender_layer":0,"head":1,"receiver_layer":2,"units":[0,1,2,3,4,5,6,7]}`。层号、头号和单元号从零起。回执只按路径计数，最终的预测和解释随策略一起冻结。[准备、查询及隔离评分](../_multiscale/DISCOVERY.zh-CN.md) · [实际干预代码](../_shared/discovery/path_model.py)
