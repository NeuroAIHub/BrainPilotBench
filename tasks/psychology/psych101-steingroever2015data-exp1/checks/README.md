Public development scorer for `psych101-steingroever2015data-exp1`. `check.sh` verifies the pinned split. The controller stages exactly nine seed files and computes response-level NLL while a pinned Docker worker runs submitted model code with only one causal prefix at a time. The prefix may contain earlier completed choices and feedback; the current target and future events stay with the controller. It never reads official Test, and `BPB_OFFICIAL_SCORING=1` is rejected. The typed sidecar `psych101-public-validation.json` distinguishes finite scores, valid infinite loss and invalid/unscored submissions.
