Public marked-response byte+EOS scorer for `psych101-wu2023chunking-exp1`. The controller holds the current target and gives the Docker worker only one causal prefix and prior response bytes per query. It verifies a normalized 257-symbol distribution at every step, sums token NLL through EOS, and averages over marked responses. Unmarked events are not targets. Invalid output is unscored; exact zero target probability is valid infinite loss with a typed sidecar. `BPB_OFFICIAL_SCORING=1` is rejected.
